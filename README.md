# SmartQuote

Voice-Ready Quotation Builder for MSMEs — built by Suktha Solutions interns.

## Stack
- Frontend: Angular 19
- Backend: Spring Boot 3.4
- Database: MongoDB

## Getting Started

Install: Node.js 22 LTS, Angular CLI 19, Java 21, Maven 3.9.x, Git 2.45+

```bash
# Backend
cd backend-springboot
mvn spring-boot:run

# Frontend
cd frontend-angular
npm install
ng serve
```
